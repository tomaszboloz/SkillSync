# SkillSync v1.4.2 — Codex cache ownership and resource accounting

Release date: 2026-09-28

## Fixed

- Historical Codex cache directories such as
  `~/.codex/plugins/cache/openai-curated/superpowers/1dc19589` are not Git
  repositories and are now excluded from generic Skill discovery.
- Active Codex caches are also excluded from the Skill detector; the Codex
  registry remains the single source of truth and the plugin is shown once.
- The Codex registry is queried once per relevant scan instead of once per
  directory, preventing inconsistent results and unnecessary CLI work.
- Existing configuration is migrated on load/save: obsolete Codex cache Skill
  paths and canonical duplicates are removed.

## Resource count

The verified local scan after canonical-path deduplication reports **679
logical resources**: **621 Skills**, **58 Plugins**, and **0 MCP** in the
currently enabled configuration. They correspond to **734 physical
installations**, with **24 logical resources shared by multiple locations**.
The previous `636` value cannot be compared directly because it mixed stale
cache/catalog entries with active manifests. The UI total is the logical count;
multi-location copies are shown separately on each resource card.

## Verification

- Rust tests: 87 passed.
- The tag-first policy remains unchanged: SemVer tags have priority; branches
  are used only for explicit overrides or repositories without SemVer tags.
