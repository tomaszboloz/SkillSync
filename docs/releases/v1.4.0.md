# SkillSync v1.4.0 — Marketplace discovery and transaction hardening

Released: 28 September 2026

## Highlights

- Lex-Machina-style repositories are now discovered below nested
  `.claude/skills` directories rather than being silently skipped.
- Same-named resources from different upstream repositories receive stable,
  independent identities. Their branches, repositories, versions and
  rollback snapshots cannot cross-contaminate.
- `seo-audit` multi-location updates resolve one upstream tag per remote before
  any snapshot or checkout. Prefix differences (`v2.4.0` versus `2.4.0`) no
  longer produce a false integrity mismatch.
- Registered Claude Code marketplace directories such as
  `~/.claude/plugins/marketplaces/n8n-mcp-skills` update through the official
  Claude Code marketplace command, not through an unsafe direct Git or package
  operation.
- A failed raw manifest download or disk write now aborts and restores every
  snapshot instead of reporting a version-only success.
- Safety snapshot identifiers use nanosecond precision; Windows URL opening no
  longer invokes a shell command.

## Upgrade

Install the DMG on Apple Silicon or Intel macOS, or the MSI/EXE on Windows
from the GitHub release assets. Existing configuration and snapshots remain
compatible. After startup, run a scan once to rebuild the source-aware resource
index.

## Verification

- Rust unit/integration tests cover nested Lex-Machina discovery, duplicate
  source isolation, registered marketplace detection, unavailable upstream
  rollback, branch validation and snapshot uniqueness.
- Frontend tests: 14 passing.
- ESLint, TypeScript, Prettier, Rust formatting and Clippy are required CI
  gates. Release CI additionally validates signed macOS/Windows updater
  artifacts and `latest.json`.

## Breaking changes

None. Resource IDs for duplicate names may gain a stable repository suffix;
this is intentional to prevent updating the wrong upstream and may require
re-saving a branch or repository override for the newly separated card.
