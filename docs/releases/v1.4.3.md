# SkillSync v1.4.3 — logical resource deduplication

Release date: 2026-09-28

## Fixed

- Identical local `SKILL.md`, `skill.json`, plugin and MCP manifests are
  grouped across monitored agent paths when no upstream URL is available.
- The UI total counts logical resources, while each card retains every
  physical installation for safe multi-location update and removal.
- Resources with different manifest content, item type, or normalized GitHub
  repository remain separate. A same-name package is not merged blindly.

## Verified local accounting

| Metric | Result |
| --- | ---: |
| Logical resources | 534 |
| Skills | 477 |
| Plugins | 57 |
| MCP | 0 |
| Physical installations | 734 |
| Resources with multiple locations | 72 |

The earlier `636` and `679` values counted some identical local copies as
separate logical resources. They were not equivalent counters. The new total
is derived from the same discovery pipeline used by the application.
