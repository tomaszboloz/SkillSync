# SkillSync v1.4.6 — Correct update sources and resource-owned errors

Released: 2026-10-07. SemVer patch, no breaking user configuration changes.

## Bug fixes

- `fix(ui)`: a failed FastMCP update no longer shows its error in the
  seo-audit or Figma detail windows. Resource errors are keyed by ID, reset
  after successful checks/retries, and support Rust's actual error payload.
- `fix(scanner)`: a non-Git skill needs a matching upstream manifest before
  a repository release is advertised as an installable skill update. Checks
  remain in the serial background queue.
- `fix(claude)`: pinned marketplace plugins follow their registered SHA.
  Figma matching the official marketplace pin is current in that channel;
  an independent `figquery` Git tag is not a marketplace update.
- `fix(cache)`: raw manifest checks are identity-specific; plugin channels
  cannot reuse another installation's cached tag result.

## What this means for the reported resources

| Resource | Result |
| --- | --- |
| seo-audit / claude-seo | Keeps canonical-name download fix from v1.4.5; v2.4.2 has a matching manifest. |
| fastmcp / PrefectHQ | The library's v4.0.11 has no matching `fastmcp` skill manifest. Source validation explains the problem and does not advertise a verified installable update. |
| Figma / Claude official marketplace | Uses the registered marketplace pin and installed commit, rather than a tag from another publication channel. |

The FastMCP skill remains installed and untouched. Updating the Python library
is a different operation and requires a safe, explicitly selected environment
adapter; this release does not invent a skill update by changing its version.

## Install or update

Use the signed in-app updater once this release and `latest.json` are published,
or download the Apple Silicon DMG / Windows MSI or EXE. Restart, then scan again.
macOS Gatekeeper instructions remain in the repository README.

Pinned plugin comparison uses Claude's registered **local** marketplace catalog.
To refresh the catalog explicitly, run:

```sh
claude plugin marketplace update claude-plugins-official
```

Then rescan in SkillSync. This resolver covers GitHub `url` sources pinned to
a 40-character commit SHA, not every possible marketplace adapter format.

## Verification

Regression tests cover error ownership, retry clearing, Rust error payloads,
marketplace pin parsing and cache boundaries. An explicitly run read-only
integration check verifies the reported FastMCP, seo-audit and Figma resources
without updating installed directories. Release builds remain gated by the
macOS and Windows CI tests and signed updater artifacts.
