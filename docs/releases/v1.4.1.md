# SkillSync v1.4.1 — Codex registry safety and accurate discovery

Release date: 2026-09-28

## Highlights

- Codex plugin caches are now recognized as owner-managed snapshots. SkillSync
  does not attempt Git operations in `~/.codex/plugins/cache`.
- Active Codex plugins are updated through the official Codex CLI after the
  marketplace registry is verified; the resulting plugin manifest is checked
  before success is reported.
- Uninstalled entries in the Codex marketplace catalog are excluded from the
  resource list. Historical versions and symlink aliases no longer inflate
  counts.
- Resources with the same name remain separate when their GitHub sources differ.

## Verification

- Rust tests: 85 passed.
- Rust clippy (`-D warnings`): passed.
- Tag-first release policy remains unchanged: SemVer repositories stay on tags;
  branches are used only for explicit overrides or repositories without SemVer
  tags.

## Upgrade

Install the macOS DMG or Windows installer from the GitHub release page. The
application will retain existing monitored paths and re-scan the Codex registry
on the next scan.
