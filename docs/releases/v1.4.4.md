# SkillSync v1.4.4 — cross-agent resource identity

Release date: 2026-09-28

## Fixed

- One skill installed in multiple monitored agent directories is shown as one
  logical resource.
- Canonical Codex, Claude Code, Gemini, Cursor and Agents paths are retained as
  physical locations for synchronized updates and removal.
- A source-less mirror is attached only when one unambiguous upstream matches
  its resource type and name; ambiguous names remain isolated for safety.
- Nested manifests in one Git worktree continue to count as one update target.
- Same-named skills from different repositories are labeled with the source
  repository rather than displayed as duplicate cards, including raw GitHub
  manifest adapters without a local `.git` directory.
