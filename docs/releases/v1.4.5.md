# SkillSync v1.4.5 — Canonical skill identity and safer manifest updates

Released: 2026-10-07. SemVer patch; no breaking user configuration changes.

## Security

Updated source-map-js to 1.2.2 for GHSA-68fv-2mgg-jv7q. The refreshed npm
audit reports no vulnerabilities. Rust advisory auditing still reports
transitive maintenance/unsoundness/yanked warnings; this is not a claim of
zero security risk or zero dependency warnings.

## Bug fixes (`fix(updater)`)

- Fixed repeated integrity failures for `seo-audit (claude-seo)` when upgrading
  from 2.4.0 to 2.4.2. Repository suffixes are now presentation only.
- The updater uses the canonical skill identity, verifies the downloaded
  manifest's name, and does not fall back from a release tag to a branch.
- One downloaded manifest is reused for all locations in a transaction.
- Explicit GitHub provenance survives replacement of the manifest and rescan.
- Bounded download time and size; interrupted responses cannot be installed.

## Installation and update

Download the macOS Apple Silicon DMG or Windows installer from this release.
Existing installations can use the signed in-app updater once the release
and its `latest.json` have been published. Restart the application after
installation, scan resources again, and retry the seo-audit update.

macOS Gatekeeper guidance is in the repository README and
[macOS signing guide](../MACOS_RELEASE_SIGNING.md). Updater signatures do not
constitute Apple Developer ID signing or notarization.

## Verification scope

Deterministic regression tests cover source labels, canonical paths, tag
resolution and manifest identity. Separately executed network tests check the
real claude-seo v2.4.2 manifest, updating two temporary installations and their
rescan. They do not modify users' globally installed resources.

FastMCP's Python library release is not a replacement manifest for a separately
authored `fastmcp` skill. Figma's Git prerelease tag and its plugin manifest
version differ upstream; the official Claude adapter remains authoritative for
marketplace-managed installations. Neither case is disguised as a successful
update by rewriting an installed version.
